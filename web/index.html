长期记忆

关掉后她不会再参考记忆、也不会主动回想；但对话仍会被记下来，重新打开时会一并整理进去 —— 所以不会留下空白。

模型把对话整理成带日期和重要度的条目。每轮只挑相关的、最近的，以及告白 / 誓言 / 关系转折 / 重大事件注入；放不下的并入「概略」而不删除 —— 这些都会登记进下面的「超长期记忆」。

联网（天气 / 搜索）

天气用 Open-Meteo，免注册、不要 key。网页搜索需要你自己申请一个搜索服务的 key（各家都有免费额度，个人用根本用不完）。查到的内容只会随"这一轮对话"交给模型参考，不会写进长期记忆、日记或回忆。

什么时候会去查：你明确说「帮我查一下 / 搜索一下 / 新闻」这类话的时候。刻意做得不宽 —— 太宽会白花搜索额度。

立绘模式

当前用的是导入模型：贴图档位只对内置模型可用，所以这里暂不可选。

原画模式 = 原图贴图（最清晰；贴图最大 8192×8192，占显存多、手机加载慢）。性能模式 = 预生成的 2048 贴图（显存占用与加载时间大幅下降，清晰度略低）。两者用的是同一个模型文件 ⇒ 动作、表情、物理、视线跟随完全一样。切换后立绘会重新加载，聊天不受影响。

她按对话换的表情（脸红、笑…）超过这个时长就自己变回默认微笑，不会一直挂着。手动点的表情不受影响；她正在说话时不会切（等这句念完）。

数据

导出存档 = 一键打包全部进度：设置与人设 · 全部存档槽 · 回忆 · 珍藏 · 长期记忆 · 闹钟。导出与存档都不包含 API Key（避免分享时泄露），换机器后需要重新填写。
